# Kizuna Intelligence

Kizuna Intelligence は、音声対話を中心に AI 系の開発を行っているチームです。

音声生成、TTS、対話体験、アプリケーション開発などを含め、AI 系の技術を継続的に公開していきます。

## 主なプロジェクト

### [Kizuna Voice Studio](https://github.com/kizuna-intelligence/kizuna-voice-studio)

日本語で声のイメージを書いて、種音声の確認から TTS モデル作成まで進められるデスクトップアプリです。

- Kizuna Voice Designer / Qwen Voice Designer に対応
- Piper TTS / Style-Bert-VITS2 / MioTTS を利用可能
- Windows / Linux / macOS 向けの配布を想定

### [Kizuna Voice Designer](https://github.com/kizuna-intelligence/kizuna-voice-designer)

日本語の説明から種音声を作るための音声デザインモジュールです。
